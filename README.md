# 과학 정원 지키기 — Illustrated Edition

초등학교 3학년 과학 복습 게임 (1인용). 5단계, 문제 40개.

## 그래픽 개선
- 식물 6종 및 좀비 2종의 독자 제작 고해상도 벡터 기반 캐릭터 원화
- 캐릭터별 대기/공격/피격 6프레임 스프라이트 시트 (총 144프레임)
- 잔디밭, 식물 카드, 그림자, 나무 테두리 및 화면 구성 개선
- 우측 상단 전체화면 버튼 유지
- 이전 버전의 깜빡임 방지 DOM 재사용 방식 유지

## GitHub Pages 배포
압축을 풀어 `index.html`, `questions.json`, `assets/`를 GitHub 저장소 루트에 덮어쓰고 Commit changes를 누르세요.

## 로컬 실행
`python -m http.server 8000` 실행 후 `http://localhost:8000` 접속.

캐릭터 그림은 원작을 복제하지 않고 익살스러운 정원 디펜스 분위기로 새로 그렸습니다.
