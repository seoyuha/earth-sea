## 화면
- 위: 태양 수 · 식물 카드 7장(키보드 1~7) · 📘 문제 풀기 · 멈춤 · 전체화면
- 가운데: 단계 이름 · 물리친 좀비 막대 · 하트 · 점수
- 아래: 단계 풍경 + 5줄 9칸 정원 (화면 크기에 맞춰 자동으로 커지고, 칸은 항상 정사각형)

## 이번에 바꾼 점
- 식물 카드를 크게: 고른 카드 강조, 태양이 모자란 카드는 흐리게, 모자랄 때 누르면 몇 개 부족한지 안내
- 🧤 식물 뽑기 추가 (태양 절반 돌려받기) — 잘못 심어도 다시 할 수 있어요
- 마우스를 올리면 심을 자리를 미리 보여 줌 (못 심는 칸은 빨간색)
- 안내 문구를 정원 가운데 아래에 크게, 단계 시작·좀비 등장·마지막 좀비·융합 알림 배너
- 태양이 100보다 적으면 📘 문제 풀기 버튼이 반짝여요
- 문제 보기 순서를 매번 섞어요 (정답 번호 외우기 방지)
- 멈춤 메뉴: 계속하기 · 식물 알아보기 · 효과음 · 처음부터(한 번 더 확인)
- 졌을 때 '이 단계 다시 하기' 선택 가능
- 단계 시작 후 8초 준비 시간, 다른 탭으로 가면 자동 멈춤
- 잔디깎이를 정원 왼쪽 띠로 옮겨 식물을 가리지 않게
- 이전 판의 오류 수정 그대로 반영: 잔디깎이 뒤 좀비가 엉뚱하게 사라지던 오류, 좀비 처리 건너뛰기, 화면 밖 좀비 공격, 칸 비율(그림 찌그러짐), 식물 피격 그림 연결, 진행 막대, 효과음 끊김, 아이패드 전체화면
- 문제 문구 수정: '너무 차가워서만' → '너무 차가워서'
- 게임에 쓰지 않는 design_reference.png는 빼서 파일 크기를 줄였어요 (11MB → 6MB)
