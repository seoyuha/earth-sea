# 🌻 과학 정원 지키기 — 초등학교 3학년 과학 복습 게임

**GitHub Pages에 바로 게시할 수 있는 정적 웹게임**입니다. Node.js나 별도 서버가 필요하지 않습니다.

## 수업 내용
첨부된 3학년 과학 교과서와 실험관찰 자료 중 **대기부터 바닷가 지형까지**의 범위를 활용했습니다. 밀물·썰물과 갯벌은 제외했습니다.

- 5단계 × 8문제 = 40문제, 쉬운 4지선다
- 정답 태양 +50, 오답 태양 +15 및 해설
- 문제를 푸는 동안 좀비 전투 일시정지
- 단계별 학습 주제 그림, 큰 보기 버튼, 모바일/태블릿 반응형 화면
- 개인별 최고 기록은 **해당 기기 브라우저에만** 저장됩니다. 학생 개인정보나 답안은 서버로 전송되지 않습니다.

## GitHub Pages 배포 (웹에서 파일 올리기)
1. GitHub 로그인 → 우측 상단 **+** → **New repository**.
2. 이름을 `science-garden-defense`로 입력하고 **Public** 선택 → **Create repository**.
3. 저장소의 **Add file → Upload files** 선택.
4. ZIP을 압축 해제한 뒤 **폴더 안의 `index.html`, `questions.json`, `assets` 폴더, `.nojekyll`**을 저장소의 최상위에 업로드합니다. **ZIP 파일 자체만 업로드하지 마세요.**
5. **Commit changes** 클릭.
6. **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
7. **Branch: main**, **Folder: /(root)** 선택 → **Save**.
8. 배포 완료 후 `https://사용자이름.github.io/science-garden-defense/` 주소로 접속해 확인합니다. 배포까지 몇 분 걸릴 수 있습니다.
9. 이 URL을 학생들에게 공유하면 됩니다. 학생은 로그인 없이 접속할 수 있습니다.

## 수정하기
- 문제: `questions.json` 편집. `answer`는 **0~3** (첫 번째 보기는 0)입니다.
- 게임 화면/규칙: `index.html` 수정.
- 캐릭터 스프라이트: `assets/` 폴더.
- 새 파일을 업로드하거나 수정해 커밋하면 GitHub Pages가 자동으로 다시 배포합니다.

## 로컬 미리보기
`python -m http.server 8000` 실행 후 `http://localhost:8000` 접속.

## 유의 사항
- 이 게임은 **1인용**이며 GitHub Pages에서는 별도 서버 없이 실행됩니다.
- 진행 중 새로고침하면 현재 게임이 초기화됩니다. 최고 점수만 저장됩니다.
- 문제 그림은 각 단계의 학습 주제를 표현하는 SVG 삽화로, 문제마다 다른 삽화는 아닙니다.
- 공개 저장소에는 학생 실명, 개인정보, 비공개 교과서 원문을 올리지 마세요.
- 배포 후 실제 갤럭시탭에서 글씨 크기, 조작, 애니메이션을 확인하세요.
