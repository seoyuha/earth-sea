# 과학 정원 지키기 — 애니메이션 디럭스

## 개선 내용
- 8종 캐릭터 × 대기·공격·피격 × 8프레임 = 192프레임 투명 PNG 스프라이트 시트
- 캐릭터별 투명 초상 PNG 8개(식물 선택 카드용)
- 5개 과학 학습 단계에 맞춘 별도 게임 배경
- 화면 크기 대응, 오른쪽 상단 전체화면, 식물 융합, 과학 40문항 유지
- 깜빡임 방지: 캐릭터 DOM 재사용, 프레임 변경 시에만 위치 갱신

## 실행
GitHub Pages: `index.html`, `questions.json`, `assets/` 전체를 저장소 루트에 업로드 후 Commit.
로컬: 압축을 풀고 폴더에서 `python -m http.server 8000` 실행 후 http://localhost:8000 접속.

## 참고
일러스트와 캐릭터는 원작 게임의 저작물 복제가 아닌 자체 제작 그래픽입니다.

## 배포 전 점검 수정 (그래픽 파일은 그대로)
- 잔디깎이가 움직인 직후 같은 줄 좀비가 또 들어오면 엉뚱한 좀비가 사라지던 오류 수정
- 좀비가 정원에 들어올 때 다음 좀비 처리를 건너뛰던 오류 수정
- 화면 밖(오른쪽 끝)에 있는 좀비를 미리 쏘지 않도록 수정
- 좀비 그림이 옆으로 눌려 보이던 비율 수정 (캐릭터 칸 = 정사각형)
- 식물이 공격받을 때 준비된 '피격' 그림이 나오도록 연결, 태양꽃이 태양을 만들 때 '공격' 그림 재생
- 진행 막대를 시간 대신 '좀비 처치 수'로 표시 (단계는 12마리 처치로 끝나므로)
- 태양이 모자란 식물 카드는 흐리게 표시
- 일시정지 안내 문구, 새 단계 시작 시 일시정지 버튼 글자 초기화
- 효과음: 소리마다 새로 만들던 오디오를 하나로 공유 (태블릿에서 소리가 끊기는 문제 예방)
- 시작 화면 안내문을 학생용 '게임 방법'으로 정리, 융합 설명을 실제 규칙과 맞게 수정
- 문제 1개 보기 문구 수정: '너무 차가워서만' → '너무 차가워서'
- 서버 없이 index.html을 바로 열어도 문제가 나오도록 문제를 파일 안에도 넣음 (questions.json이 있으면 그것을 먼저 사용)
- 아이패드 사파리 전체화면 지원, 전체화면이 안 되는 기기에서는 경고창 대신 안내 문구
